# Haven Furniture (Heaven Furniture Mart)

Luxury, bespoke handcrafted furniture showcase and interactive 3D configurator website built with React 18, Vite, Tailwind CSS, and Framer Motion.

## Features

- **Interactive 3D / Configurator**: Customizer for wood finishes, upholstery materials, dimensions, and hardware.
- **Virtual Showroom & Collections**: Categorized gallery (Living, Dining, Bedroom, Office).
- **Craftsmanship Journey**: Visual narrative of materials and artisanal woodworking.
- **WhatsApp Direct Booking**: Instant consultation and quotation chat integration.
- **Bilingual Localization**: English and Bengali language support.
- **Responsive & Micro-Interactions**: Smooth animations, custom cursor, and mobile-friendly UI.

## Getting Started

### Prerequisites

- Node.js (version 18+ recommended)
- npm

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
